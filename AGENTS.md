# Agent notes

## Keep the README up to date

Every commit must leave `README.md` accurate. When a change adds, changes or
removes behavior, a requirement, a config field or a file path, update the
README in the same commit, not in a later catch-up. Before committing, check
the parts a change can affect: the status lines, **Known bugs**, the config
docs, the **Layout** paths and any caveats the change makes stale.
